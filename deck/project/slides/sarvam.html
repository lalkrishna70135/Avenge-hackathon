Every Sarvam reply is cached on disk, keyed by the exact request, so the whole demo replays offline and a stopped run resumes without paying twice.

We split work by model. The reasoning model is slower, five to fifteen thousand reasoning tokens per call, so it does the jobs where quality matters: rewriting the prompt, condensing it, and judging calls. The conversational model has no reasoning step and answers in about a second, so it plays both sides of simulated calls. Speech-to-text and text-to-speech close the loop for real recordings and the live demo.
