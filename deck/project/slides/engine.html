Layer 3 · The A/B engine

Rules fixed before the test starts, applied automatically

Method

  • Routing: sha256(salt:buyer) mod 10,000, so a buyer always hears the same prompt
  • Primary: lead created per buyer within 2 h of their first call; any disposition can be the goal
  • 5 looks: O'Brien-Fleming win line, Pocock harm line
  • Guardrail: call duration B/A under +15%; hard stop at +30%
  • Plan: 24,581 buyers, 2,459 on B, detects +3 points

Every experiment config is immutable and hashed together with the exact prompt text. The router is a deterministic hash, so assignment is sticky and needs no lookup. The primary goal defaults to lead created, but any set of dispositions can be chosen as the goal. Each buyer is scored on their calls within two hours of their first call and enters a look only once that window has closed, so an outcome the engine has seen never changes between looks; 81 percent of real repeat calls come within an hour. The test is group-sequential: five looks planned in advance, with boundaries from alpha spending, so peeking does not inflate false wins. The primary decides and duration can only veto: a win with calls more than 15 percent longer is held, B goes to zero, and a named approver promotes or rejects it, logged with their name and reason. Every look, decision and routing change goes to an append-only log with the evidence and the rule that fired.
