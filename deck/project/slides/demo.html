The dashboard is a Streamlit app with ten tabs. The Live call tab is the end-to-end moment: a buyer ID goes through the same hash router as live traffic, Sarvam speech-to-text hears you, the VANI bot answers with prompt A or B, and Sarvam text-to-speech speaks the reply. The bot is given the product's real IndiaMART spec fields, so for TMT steel bars it asks tonnage, grade and diameter. At the end, the same blind judge audits the call. On the Experiments tab, a held win waits for a named approver, and their decision joins the log. Everything else replays cached results, so it works offline.
