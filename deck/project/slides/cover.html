Problem Statement 05 · Prompt A/B testing & auto-rollout

VANI Prompt Lab

Test every prompt change on real calls, simulated buyers and live traffic before it reaches every buyer.

Built on Sarvam: speech-to-text · sarvam-105b · text-to-speech

Real VANI data: 1,000 call-log rows · 594 recordings

VANI is IndiaMART's buyer-side voice bot. Its behaviour lives in one 163 KB prompt. Every change to that prompt is a bet on thousands of live calls. We built a lab that tests a change three ways: against real recorded calls, in simulated calls with buyers modelled on real ones, and in a statistically sound A/B test with automatic rollout or rollback.
