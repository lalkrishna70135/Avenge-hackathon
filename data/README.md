# data/

Input data is not included in this repo. Add your own files here before running the pipeline:

| Path | What it is |
|---|---|
| `Call_Logs_Hackathon.csv` | VANI call log export |
| `base_prompt.txt` | The base VANI prompt that variants are tested against |
| `catalog/ref_category_taxonomy.csv`, `catalog/ref_category_specs.csv` | MCAT taxonomy and spec reference tables |
| `recordings/` | Call recordings (`.mp3`); `scripts/transcribe_calls.py` copies and transcribes them |
| `sarvam/` | Generated transcripts and core prompt (created by the scripts) |

`call_quality_matrix.md` is included.
